# Creating a Reusable Controlled Component for React Hook Form #

This guide explains how to convert a custom React component into a reusable controlled component using the `useController` hook from React Hook Form (RHF). This approach enables your form inputs to leverage RHF's
validation, state management, and other features more effectively than using the `Controller` component.

## Overview ##

React Hook Form is a popular library for managing form states in React applications. By turning your custom components into controlled components, RHF can handle their state efficiently and offer improved performance
and flexibility.

## Steps to Convert a Custom Component ##

### 1. Create Your Custom Component ###

Begin by defining your custom component. Here's an example of a simple `TextInput` component in TypeScript:

```typescript
import React from 'react';

type TextInputProps = {
  value: string;
  onChange: (e: React.ChangeEvent<HTMLInputElement>) => void;
  onBlur: () => void;
  name: string;
  label: string;
  error?: { message: string };
};

const TextInput: React.FC<TextInputProps> = ({ value, onChange, onBlur, name, label, error }) => (
  <div>
    <label htmlFor={name}>{label}</label>
    <input
      id={name}
      name={name}
      value={value}
      onChange={onChange}
      onBlur={onBlur}
      style={{ borderColor: error ? 'red' : 'black' }}
    />
    {error && <span style={{ color: 'red' }}>{error.message}</span>}
  </div>
);

export default TextInput;
```

### 2. Integrate with React Hook Form Using `useController` ###

The `useController` hook provides a more granular approach to connect your custom component to RHF, offering better handling of field interactions like value changes and blur events.

#### Using the `useController` Hook ####

```typescript
import React from 'react';
import { useForm, useController } from 'react-hook-form';
import TextInput from './TextInput';

type FormValues = {
  firstName: string;
};

const MyForm: React.FC = () => {
  const { handleSubmit, control } = useForm<FormValues>();
  const { field, fieldState } = useController({
    name: 'firstName',
    control,
    defaultValue: ''
  });

  const onSubmit = (data: FormValues) => {
    console.log(data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <TextInput
        label="First Name"
        {...field}
        error={fieldState.error}
      />
      <button type="submit">Submit</button>
    </form>
  );
};

export default MyForm;
```

### Key Considerations ###

- **Props Forwarding**: Ensure you forward necessary props (`value`, `onChange`, `onBlur`) so RHF can manage the input's state.
- **Default Values**: Always define a `defaultValue` to avoid uncontrolled to controlled input warnings.
- **Validation and Errors**: Utilize `fieldState` to access validation errors, which can be displayed within your component.

## Conclusion ##

By following these steps, you have successfully adapted a custom React component into a reusable controlled component using the `useController` hook for integration with React Hook Form. This approach enables optimal
form state management and data validation in React applications.

For more extensive details, consult the [React Hook Form documentation](https://react-hook-form.com/), which provides insights into advanced topics such as comprehensive form validation and error handling.

If you prefer using the `Controller` component for cases where the container pattern is more suitable, explore its usage [here](https://react-hook-form.com/docs/usecontroller).
